# Contributing to Maneuver

Testing and bug reports are welcome.

## Reporting a Problem

Please include:

1. What maneuver(s) were active.
2. What you expected Maneuver to display.
3. What it displayed instead.
4. Whether another Puppetmaster was nearby.
5. Any useful information shown by `/maneuver debug`.
6. Steps that reproduce the issue, if known.

## Code Changes

Keep changes focused and preserve compatibility with HorizonXI and Ashita v4. Test HUD behavior, maneuver expiration, multiple stacks, and local-player filtering before submitting a change.
